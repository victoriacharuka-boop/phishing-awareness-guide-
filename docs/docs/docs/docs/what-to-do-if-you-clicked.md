# What to Do If You Clicked

Do not panic. Acting quickly limits the damage.

| Step | Action |
|---|---|
| 1 | Disconnect from the network if you downloaded a file |
| 2 | Change the password for any account you entered it on, from a safe device |
| 3 | Turn on MFA if it is not already active |
| 4 | Report it to the IT or security team straight away |
| 5 | Note what you clicked, entered and when |
| 6 | Watch your accounts for unusual activity |

Reporting a mistake early is always better than hiding it.
