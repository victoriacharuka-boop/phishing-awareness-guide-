# Types of Phishing

| Type | How it reaches you | Example |
|---|---|---|
| Email phishing | Mass emails pretending to be a known brand | A fake delivery notice |
| Spear phishing | Targeted email using details about you | A message that appears to come from your manager |
| Smishing | SMS or text messages | "Your parcel is held, pay a fee here" |
| Vishing | Phone calls | A caller claiming to be from your bank |
| Fake websites | Copies of real login pages | A look-alike sign-in page |

## Common defences
- Use multi-factor authentication so a stolen password is not enough.
- Verify requests through a second channel, such as calling a known number.
- Keep software and browsers updated.
- Report suspicious messages to the IT or security team.
