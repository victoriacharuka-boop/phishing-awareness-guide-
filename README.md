# Phishing Awareness Guide

A short, plain-language guide to help staff and students recognise phishing attacks and respond safely.

## Contents
- `docs/what-is-phishing.md`: what phishing is and why it works
- `docs/spot-a-phishing-email.md`: warning signs and a fictional example
- `docs/types-of-phishing.md`: the main kinds of phishing
- `docs/what-to-do-if-you-clicked.md`: steps to take after a mistake

## Who is it for?
Anyone who uses email, messaging apps or the web. No technical background is needed.

## Golden rule
If a message is unexpected, urgent or asks for a password or money, stop and verify it through a different channel before acting.

## Note
All examples in this repository are fictional. It contains no real credentials or personal data.
